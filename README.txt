HomeGenius Survey App
Upload ALL files in this folder (index.html, manifest.webmanifest, sw.js and the 3 icon-*.png files)
to a web host (GitHub Pages or Netlify). Then open the address in Chrome on the tablet and
choose the menu (3 dots) > Install app (or Add to Home screen).
In the app tap Settings and enter your Google web app URL and secret key to enable Save & Email.
